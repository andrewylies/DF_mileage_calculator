# ⏰ [DF] Can I Leave Early?

사내 인트라넷(Designfever) 근태 캘린더에서 근무시간을 자동으로 집계하고 마일리지(±시간)를 계산해주는 Chrome 확장 프로그램입니다. 페이지 우측 하단의 작은 원형 버튼으로 시간 계산기도 함께 제공합니다.

- 현재 버전: v1.3.0 (Manifest V3)
- 웹 스토어: https://chromewebstore.google.com/detail/kpjjaacjiadiipdakgfijnbabhkfkmgn


## 주요 기능

- 근무시간 자동 집계 및 마일리지 계산
  - 캘린더에서 각 날짜의 "총 업무시간 HH:MM" 텍스트를 자동으로 파싱해 총 근로시간을 계산합니다.
  - 반차가 있는 날은 필수 근로시간을 4시간으로 자동 보정하여 마일리지를 정확하게 표시합니다.
  - 기본값으로 "오늘"은 집계에서 제외되며, 필요 시 버튼으로 포함/미포함을 전환할 수 있습니다.
- 남은 근로시간 태그 표시
  - 페이지 상단 태그 영역에 "남은 근로시간"을 추가로 표시합니다.
- 플로팅 시간 계산기(Floating UI)
  - 페이지 우측 하단에 작은 원형 🤔 버튼이 생깁니다. 클릭하면 계산기 패널이 펼쳐집니다.
  - 첫 번째 행은 기준 시간, 이후 행은 + 또는 - 버튼으로 더하거나 뺄 시간을 입력할 수 있습니다.
  - "줄 추가" 버튼으로 입력 행을 5개씩 빠르게 추가할 수 있습니다.
  - "총 시간: 8시간 30분"처럼 결과가 즉시 계산·표시됩니다.
  - 붙여넣기(paste)만 해도 자동 인식: 예) "총 업무시간 08:19", "-0시간 24분", "8h 30m".
- 설치 후 별도 설정 없이 즉시 동작
  - 외부 라이브러리에 의존하지 않고 바닐라 JavaScript만 사용합니다.


## 동작 방식 (간단 설명)

- DOM 크롤링 기반
  - 각 날짜 박스(`.calendar-date`) 내부에서 근무 이벤트(`.calendar-event.is-warning`)를 찾고, 텍스트 중 "총 업무시간 HH:MM" 패턴을 추출합니다.
  - 날짜에 "반차" 텍스트가 있고 실제 근무 기록이 있다면, 해당 날짜의 필수 시간을 4시간으로 간주합니다.
  - 오늘 날짜(`.is-today`)는 기본적으로 제외하며, "오늘 포함/미포함 계산" 버튼으로 실시간 전환합니다.
- UI 반영
  - 상단 카드/태그 영역에 "총 근로시간"과 "마일리지(±시간)", "남은 근로시간"을 추가 표시합니다.
  - 우측 하단 플로팅 버튼(🤔)을 통해 시간 계산기를 토글할 수 있습니다.
- 보안/권한
  - Manifest V3의 `content_scripts`만 사용하며, host 권한은 특정 페이지(회사 인트라넷)로 최소화되어 있습니다.
  - 네트워크로 외부 전송을 하지 않으며, 브라우저 저장소를 사용하지 않습니다.


## 설치 방법

1) Chrome 웹 스토어에서 설치 (권장)
- 링크: https://chromewebstore.google.com/detail/kpjjaacjiadiipdakgfijnbabhkfkmgn
- 설치 후 회사 인트라넷 근태 캘린더 페이지에 접속하면 자동으로 동작합니다.

2) 로컬(개발용) 설치
- 이 저장소를 클론 또는 다운로드합니다.
- Chrome 주소창에 `chrome://extensions` 입력 → 개발자 모드 On → "압축해제된 확장 프로그램을 로드" → 이 폴더를 선택합니다.
- 업데이트 시에는 확장 프로그램 카드의 "새로고침" 버튼을 눌러 반영합니다.


## 사용 방법 (요약)

- 근태 캘린더 페이지 접속 시 상단 카드/태그 영역에 아래 정보가 자동 표시됩니다.
  - 총 근로시간: "HH시간 MM분"
  - 마일리지(±시간): 예) `-1시간 30분`은 남은 시간, `+0시간 45분`은 초과 근무를 뜻합니다.
  - 남은 근로시간: 기준 근로시간과 당일/월간 근무 누적에 따라 자동 계산됩니다.
- 오늘 포함/미포함 토글
  - 상단 영역 아래에 버튼이 나타납니다. 클릭하여 "오늘"을 집계에 포함하거나 제외할 수 있습니다.
- 시간 계산기 사용
  - 우측 하단의 원형 🤔 버튼을 클릭해 계산기 패널을 열고, 시간/분을 입력합니다.
  - 붙여넣기만 해도 자동 인식합니다: 예) "총 업무시간 08:19", "-0시간 24분", "8h 30m".
  - `줄 추가`로 5개 행을 빠르게 추가하고, `+/-`로 더하기/빼기 연산을 지정합니다.
  - `계산` 버튼을 누르면 "총 시간: HH시간 MM분"으로 결과가 표시됩니다. `초기화`로 다시 시작할 수 있습니다.


## 제한 사항 및 주의

- 회사 인트라넷의 DOM 구조(클래스/텍스트)가 변경되면 동작이 달라질 수 있습니다.
- 인트라넷 URL에만 스크립트를 주입합니다


## 개발 가이드

- 기술 스택: Chrome Extension Manifest V3, Vanilla JavaScript, DOM API
- 빌드: 없음 (바닐라 JS 기반)
- 소스 구조
  - `manifest.json` — 확장 프로그램 메타 정보 및 content script 설정
  - `scripts/content.js` — DOM 파싱, 마일리지/남은 시간 계산, 플로팅 계산기 UI
  - `images/` — 확장 아이콘 세트
